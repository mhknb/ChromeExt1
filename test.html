AI Content Exporter - Test Page

Instructions:

  1. Close the file picker dialog in Chrome
  2. Manually navigate to: /Users/hakanb/Documents/Projects/ChromeExt1
  3. Click "Select" to load the extension
  4. Once loaded, visit ChatGPT, Claude, Gemini, or DeepSeek
  5. The extension should add export buttons to AI responses

Extension Features:

  • ✅ Clean text copy (removes markdown)
  • ✅ Export to TXT
  • ✅ Export to DOCX (with LaTeX support)
  • ✅ Export to PDF (with KaTeX rendering)

Supported Platforms:

  • ChatGPT (chat.openai.com, chatgpt.com)
  • Claude (claude.ai)
  • Gemini (gemini.google.com)
  • DeepSeek (chat.deepseek.com)

Troubleshooting:

If the extension doesn't load:

  1. Make sure Developer Mode is enabled in chrome://extensions/
  2. Check that all files are present in the directory
  3. Try refreshing the extensions page
  4. Check the console for any error messages
